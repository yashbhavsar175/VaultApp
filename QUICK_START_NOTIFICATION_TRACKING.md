# 🚀 Quick Start: Notification Tracking

## For Users

### Enable in 3 Steps:
1. **Open Settings** (4th tab)
2. **Toggle "Notification Tracking"** to ON
3. **Grant permission** in Android Settings

### What You Get:
✅ Auto-track Slice transactions  
✅ Auto-track CRED transactions  
✅ Auto-track GPay transactions  
✅ Auto-track PhonePe transactions  
✅ No manual entry needed  

---

## For Developers

### Build & Test:
```bash
npm run android
```

### Debug Logs:
```bash
adb logcat | grep -E "NotificationListener|NotificationProcessor"
```

### UI Location:
```
Settings → Features → Notification Tracking
```
