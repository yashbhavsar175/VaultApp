## 💡 Kaise Kaam Karta Hai

### Pehli Baar Setup:
```
1. Settings → Financial Setup → Bank & Card Setup
2. Apne saare banks aur cards add karo
3. Last 4 digits zaroor daalo
4. Account type select karo
5. Save karo
```

### Automatic Detection:
```
1. Jab bank se SMS aayega
2. App automatically detect karega
3. Last 4 digits se match karega
4. Transaction create ho jayega
5. Notification milega
```

### Example:
```
SMS: "Rs 500 debited from A/c XX1234 on 13-May"
      ↓
App: "Oh! 1234 = HDFC Savings Account"
      ↓
Transaction: ₹500 expense created
      ↓
Notification: "Transaction detected from HDFC Bank"
```

## ❓ Common Questions

**Q: Bank setup button kahan gaya?**
A: Settings → Financial Setup → Bank & Card Setup me hai

**Q: Har SMS ke liye manually add karna padega?**
A: Nahi! Ek baar bank add karo, baad me automatic detect hoga

**Q: Multiple accounts kaise add karein?**
A: Har account ke liye alag entry banao with unique last 4 digits

**Q: Credit card aur debit card dono add kar sakte hain?**
A: Haan! Account type me select karo - Savings ya Credit Card

**Q: UPI transactions detect honge?**
A: Haan! UPI IDs add karo, phir UPI transactions bhi detect honge

**Q: Agar galat bank add ho gaya?**
A: Edit button (✏️) se edit karo ya Delete button (🗑️) se delete karo

**Q: SMS parser test kaise karein?**
A: Settings → Financial Setup → SMS Parser Test
