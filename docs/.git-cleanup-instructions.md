# Git History Cleanup - Remove Exposed API Keys

## ⚠️ CRITICAL: Do this IMMEDIATELY!

### Step 1: Revoke/Regenerate ALL exposed keys
Go to respective services and regenerate:
- ✅ Google API Key (Gemini) - https://console.cloud.google.com/apis/credentials
- ✅ Supabase Keys - https://supabase.com/dashboard/project/_/settings/api
- ✅ Google OAuth Client ID - https://console.cloud.google.com/apis/credentials

### Step 2: Remove sensitive files from Git history

```bash
# Install BFG Repo-Cleaner (faster than git filter-branch)
# Download from: https://rtyley.github.io/bfg-repo-cleaner/

# OR use git filter-repo (recommended)
pip install git-filter-repo

# Remove .env file from entire history
git filter-repo --path .env --invert-paths

# Remove old config/index.ts versions with hardcoded keys
git filter-repo --path src/config/index.ts --invert-paths --force

# OR use BFG (if you downloaded it)
java -jar bfg.jar --delete-files .env
java -jar bfg.jar --replace-text passwords.txt  # Create passwords.txt with your exposed keys
```

### Step 3: Force push (⚠️ WARNING: This rewrites history!)

```bash
# Backup your repo first!
git clone your-repo.git backup-repo

# Force push cleaned history
git push origin --force --all
git push origin --force --tags
```

### Step 4: Verify .gitignore is working

```bash
# Check if .env is ignored
git check-ignore -v .env

# Should output: .gitignore:XX:.env    .env
```

### Step 5: Update all team members
Tell everyone to:
```bash
git fetch origin
git reset --hard origin/main  # or your branch name
```

## Alternative: Start Fresh (Nuclear Option)

If the repo is new and doesn't have important history:

```bash
# Delete .git folder
rm -rf .git

# Reinitialize
git init
git add .
git commit -m "Initial commit with secured keys"
git remote add origin your-repo-url
git push -u origin main --force
```
